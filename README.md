# Ethereal Dimension — Site

Marketing site for **Ethereal Dimension** — frontier AI for the built environment.

- **Stack:** Next.js (App Router) + TypeScript + Tailwind CSS v4
- **Deploy:** Vercel (etherealdimension.io)
- **Design direction:** "Ethereal Editorial" — see `PRODUCT.md` and `DESIGN.md`

## Development

```bash
npm install
npm run dev      # local dev on http://localhost:3000
npm run build    # production build
npm run lint     # eslint
```

## Pages
- `/` — home (hero, deployed work, Hylios, CTA)
- `/ethereal-search` — Ethereal Search preview page

## Assets
Real deployment/product media live in `public/assets/` (from the existing production site).
